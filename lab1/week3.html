Go live together

Publish your game 🚀

  1. New repository: name my-arcade, Public, add a README
  2. Add file, Upload files: index.html prd.md game.html
  3. Settings, then Pages
  4. Deploy from a branch, main, / (root), Save
  5. Wait 2 minutes, refresh, click Visit site 🎉

🎓 Work with a partner: take turns reading each step and clicking. Help each other spot the right setting.

⏳ No Visit site button yet? Wait another minute. The first time can take up to 10 minutes.
