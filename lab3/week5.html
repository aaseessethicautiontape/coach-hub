Session 3 · let the server decide

🛡️ Every server function starts with: who is this?

import { initializeApp, cert, getApps } from 'firebase-admin/app';
import { getAuth } from 'firebase-admin/auth';
import { getFirestore } from 'firebase-admin/firestore';
if (!getApps().length) {
  initializeApp({
    credential: cert(JSON.parse(process.env.FIREBASE_SERVICE_ACCOUNT))
  });
}
export const db = getFirestore();
export async function playerId(req) {
  const token = (req.headers.authorization || '').replace('Bearer ', '');
  return (await getAuth().verifyIdToken(token)).uid;
}

Session 3 · transactions

🔁 One catch, one time + 🏁 Honest Catch Race

const ref = db.collection('encounters').doc(encounterId);
const result = await db.runTransaction(async (t) => {
  const e = (await t.get(ref)).data();
  if (!e || e.uid !== uid) return { status: 403 };
  if (e.used) return { status: 409 };
  const caught = Math.random() <
    Math.min(0.9, 0.18 + e.captureRate / 255 * 0.58);
  t.update(ref, { used: true, caught });
  return { status: 200, caught };
});
// TROUBLESHOOTING
🟣 401 on everything

🧩 JSON.parse error
Only part of the key got pasted. Paste the whole file in Vercel again, then pull again.
🪟 Works live, fails on vercel dev
Common on Windows. Ask Codex to make lib/admin.js handle both newline formats of the key.
🎲 Catch failed but used: true?
That's the dice roll, not a bug. The encounter is spent either way.
