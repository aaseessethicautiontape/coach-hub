# Coach Hub

Aasees Sethi's class hub for AI Project Lab 1 and Lab 3 at Caution Tape (Newmarket, Sundays).

- `index.html` is the dashboard
- `lab1/`, `lab3/` hold the weekly slide decks (one HTML file each, works offline)
- `guides/` holds the teacher guide PDFs

The dashboard and weekly slide decks are open. Teacher guide PDFs use PDF
password protection; keep individual passwords separately from this folder.
The new Week 3 guides use the `LABXWeekX181026` pattern, with the lab and week
numbers substituted for `X`.

Static site, no build step. Deploy with `npx vercel` from this folder.
